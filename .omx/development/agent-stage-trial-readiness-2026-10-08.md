## 1. 目标与基线

将已通过 FA1 工程门禁的版本推进到「可以交给陌生新手做受控试用」的状态，补齐可机器验证的无障碍、失败语义和安装布局检查，不再为已关闭的小修反复交接。

- 基线是当前未提交工作区，不是旧提交 `0c3e3b3` 的裸 checkout；版本/阶段保持根目录 VERSION/PHASE。
- 历史证据：`final-candidate-repair-2026-10-08.md`；616 个 C#、448+1 skip Python、5 个真进程、13 个负例和两次 UI 冒烟是上一批结果，不冒充本批重跑。
- 当前大量用户/其他 Agent 成果尚未提交。此次使用同一工作区、明确文件所有权；不能重置、覆盖，不能从旧 HEAD 新建分支遗漏成果。
- 用户已要求统筹继续分派下一阶段；本批不包含安装、外发提醒、提交、推送、发布或改变系统显示设置。

## 2. 协作规则

1. 各执行者先读 AGENTS.md、开发协议、current/handoff 与本任务书。
2. 你不是唯一开发者；只改分配文件，保留其他修改，不写共享开发记录。各包交付自己的 MD，统筹合并记录。
3. 先列真实缺口与最小方案，再实现与回归；不要为了增加测试数复制已有断言。
4. 不启动生产 App 测试宿主、不读取或写入正式账本，不导入真实凭据，不调用真实外发渠道。
5. .NET 构建、桌面启动、安装布局运行由统筹串行调度，避免共用 bin/obj/8765 相互干扰；Python 纯测试可独立运行。
6. 新发现的小而明确的跨包问题由统筹直接收口；架构或新产品范围变化先报统筹，不自行扩张。
7. 每包给出改动文件、通过/失败/未运行项、命令及证据、遗留边界。失败也保留，不能以重试筛选绿灯。

## 3. 工作包

### A：换汇结果卡的可访问语义与键盘可达性

所有权：`src/Caishenfolio.Desktop/Wealth/FxCarryView.xaml`、同名 `.xaml.cs`、新增 `tests/Caishenfolio.Desktop.Tests/FxResultAccessibilityTests.cs`、`acceptance/tr1-a-accessibility.md`。

- 检查真实动态结果卡的 WPF 可访问名称、读屏可获得的信息、Tab 可达性；优先补实际缺口，不做页面重设计。
- 每条路径必须可以获得路径名、币种、毛/净额、成本未知/净额已计入等状态；读到的应随当前结果变化，不能滞留旧卡。
- 使用现有隔离 WpfTestHost 和生产渲染路径补正式回归；未知成本与零成本至少分别验证。
- 不改变金融公式、请求归属、费用三态或账本行为；不修改公共测试宿主。
- 本包可以证明自动化语义与聚焦属性，不能代签 Narrator 实际朗读、真人 Tab 体验或多 DPI 验收。
- 完成代码后通知统筹调度 .NET 与真实应用冒烟，未经调度不要与其他包同时构建/启动。

### B：数据失败与恢复的确定性契约

所有权：新增 `tests/python/test_trial_failure_contracts.py`、`acceptance/tr1-b-data-failures.md`。需要产品补丁时先报告具体反例，由统筹接手或扩权。

- 对现有路由与真实生产适配/组合逻辑做缺口映射，使用注入故障而非断开用户网络。
- 优先覆盖超时/不可重试错误、部分通道失败、全通道失败、恢复后新请求的状态不污染；换汇缺报价不得变成确定净额，证据卡不得把缺失当利好。
- provider/source/synthetic 与错误状态应如实；不得用 fixture 冒充真实上游验证。
- 不重复已有缺标的/缺币种简单单测，不为通过测试修改业务预期。
- 以 managed venv、`-W error` 运行新增与相关 Python 测试，提交证据。真实网站连通性与断网 UI 体验依然独立待验。

### C：仓库外安装布局的安全可验证启动

所有权：`scripts/installed_smoke.ps1`、新增 `scripts/installed_smoke_negative.ps1`、`acceptance/tr1-c-installed-layout.md`。

- 现脚本仅看到窗口就通过、没有测试状态根隔离，且会覆盖报告：不能原样运行。
- 将它改为一次性外部临时安装布局 + 合法隔离状态根 + 强制 fixture；报告区限定工作区，拒绝已有报告/重解析路径，不触碰正式账本或原日志。
- 校验主窗口/首次引导/健康状态来自本次进程树，provider=fixture 且 synthetic=true；仅有窗口标题不算核心可用。
- 清理仅限此次创建的已验证目录与进程树；环境变量恢复；不杀既有进程，不自动 msiexec 安装。
- 可复用 ui_smoke 的生产函数，但不能修改该共享脚本，不能复制一套放宽的安全检查；如需调整共用接口报告统筹。
- 增加不启动桌面的生产函数负例；准备 `SkipBuild` 等串行集成入口，实际 Release 构建与桌面运行等待统筹调度。
- 安装布局通过不等于 MSI 安装/升级通过；不关闭对应人工/环境项。
