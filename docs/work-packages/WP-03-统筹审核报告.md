## 退回的唯一理由：Codex #4

`FxAlertRule.StableId` 在 `Id` 为空时回落为 `Kind:Pair:Base/Target/Held`（`FxAlertRuleEvaluator.cs:85-87`），而设置页创建规则时**从不赋 `Id`**（`PortfolioSettingsWindow.xaml.cs:407/421/448/467` 四处构造器均无 `Id`）。

于是：

- 身份实际退化为**分类**，不是身份。
- A7 之所以绿，是因为它比较的是**阈值不同**的规则，`Level` 能把它们分开。
- **两条只有固定费不同的规则（同 Kind、同币种对、同阈值）仍然共享键，仍然互相压制。**

任务书 D5 要求的是「规则 id + revision + level」。id 字段存在但在生产路径上永不赋值，等于没有。本包目标之二「分档换汇的多条规则各自独立送达」因此**只在测试里成立**。

Codex 的结论原文是「**交付前先修第 1–4 条**」，#4 在其中。
