## 1. 做了什么（按目标）

| 目标 | 落点 |
| --- | --- |
| R1 现金流 vs 市值断言分离 | 新流水类型 `BalanceAssertion`：只写「这个账户今天值多少」，永不进现金、永不进外部流（`LedgerTransaction.BalanceAssertion`、`PositionCalculator.Replay`） |
| R2 账户估值模式二选一 | `AccountValuationMode { Detail, Balance }`、`Account.Mode`、schema v10 列 `accounts.mode`；写入侧校验 `PortfolioStore.ValidateValuationModes`（普通写入与打新台账两条路径都过它）；余额账户的持仓/现金在估值层被排除并给警告 |
| R3 账户间转移：账户层是外部流、组合层是内部流 | 新流水类型 `Transfer`（一行两条腿），`ExternalFlow.CrossesPortfolioBoundary`，`LedgerState.FlowsForAccount` 与组合层 `ExternalFlows` 分开 |
| R4 跨币种转移继续走 `FxExchange` | 不并进 `Transfer`；界面统一叫「转到我的另一个账户」，按两边币种自动选类型 |
| R5 多币种收益率 | `HistoricalFxConverter`（只认当日观测行）→ 每笔外部流按发生日折算后解 XIRR/TWR；缺率 → 结果「不完整」并点名缺失日期，绝不用今日汇率、绝不静默 null；**折不了时账户的净投入/累计收益/年化一律未知，不给 0** |
| R6 schema v10 迁移 | `if (current < 10)` + 列存在性守卫（幂等）、迁移前留 `.bak`、既有账户一律仍是 `Detail` |
| R7 冲正/导出/CSV 三处补齐 | `Reversal` 对两个新类型逐一验证（A9）；导出各自命名、转账不重复打印金额；CSV 导入明确拒绝并给原因 |
| 目标 3 四个数 | `AccountSummary`（总资产 / 累计收益 / 资金加权收益率 / 年化），账本页「账户汇总」表；未知显示「未知」+ 原因，不是 0 |
| 目标 4 新增记录对话框 | `RecordWindow`：四条操作、字段随操作与币种显隐、跨币种只填两边金额（汇率只读显示）、余额模式限制、保存前不写账本 |
